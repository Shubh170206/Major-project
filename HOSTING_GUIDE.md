## ✅ Option A: Netlify Drop (recommended — drag & drop, 3 minutes)

1. Put ONLY these 3 files into a new folder named `agrisense`:
   - `index.html`, `style.css`, `app.js`
2. Go to **https://app.netlify.com/drop**
3. Sign up free with your **Google account** (1 minute)
4. **Drag the `agrisense` folder** into the dotted box on that page
5. Done — Netlify gives you a live URL like `https://agrisense-yourname.netlify.app`
6. (Optional) Site settings → Change site name → `agrisense-<yourname>` for a clean URL
7. Share that URL +QR code in your report, PPT and resume

To update the site later: drag the folder again into your site's "Deploys" page.

## ✅ Option B: GitHub Pages (good for resume — shows GitHub profile too)

1. Create free account at https://github.com
2. New repository → name: `agrisense` → Public → Create
3. "Upload files" → drag `index.html`, `style.css`, `app.js`, `README.md` → Commit
4. Settings → Pages → Source: `main` branch → Save
5. Live in ~1 minute at `https://<your-username>.github.io/agrisense/`
